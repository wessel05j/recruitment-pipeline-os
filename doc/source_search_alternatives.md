# Source Search Alternatives

1. **GitHub API**
   - Best for developers
   - Search by language, location, repos, activity

2. **Brave Search API**
   - Search public web
   - Finds portfolios, blogs, GitHub links, conference pages

3. **Stack Exchange API**
   - Finds technical users by reputation, tags, activity

4. **People Data APIs**
   - Examples: People Data Labs, Apollo, Proxycurl
   - Closest to “search people database”
   - Needs legal/GDPR check

5. **Job-board / Talent APIs**
   - Indeed, Wellfound, niche job boards
   - Usually requires partner/paid access

## Best MVP

GitHub API.
