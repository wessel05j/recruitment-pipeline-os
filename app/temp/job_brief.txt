Role title: Junior–Mid RPA / Automation Developer

Location: Norway (candidate must be located in Norway)
Work setup: Fully remote
Employment type: Full-time
Seniority: Junior to Mid-level (approx. 1–4 years relevant automation/software experience)
Company / industry context: Internal accounting and back-office automation for a Norwegian organisation — automating repetitive finance, bookkeeping and back-office data tasks to reduce manual work and improve data quality.

Role summary: Build, deploy and maintain automation solutions to replace repetitive accounting and back-office tasks. Primary focus on Python-driven scripts and data work (Excel/CSV, API integrations), with occasional use of RPA platforms and ERP connectors. Collaborate with accounting staff to translate manual processes into robust automated workflows.

Main responsibilities:
- Design and implement end-to-end automations for accounting/back-office tasks (data extraction, transform, load, reconciliation).
- Develop Python scripts and utilities for CSV/Excel processing, data validation and transformation.
- Integrate with third-party systems via REST APIs (JSON), extract and push data to accounting/ERP systems.
- Build reliable error handling, logging and retry strategies; create documentation and runbooks for handover to operations.
- Test and validate automation outputs with accounting stakeholders; iterate on feedback.
- Maintain and update automations; support ad-hoc data cleanup and troubleshooting.

Required skills:
- Practical experience building automation using Python for data processing.
- Strong Excel / CSV handling skills (parsing, transformation, formula familiarity; ability to script Excel workflows).
- API integration experience (REST/JSON) and handling HTTP requests/responses in code.
- Solid data-processing skills: parsing, validation, mapping, basic ETL patterns.
- Problem-solving and ability to translate manual accounting steps into automated logic.

Required technologies / tools (for sourcing/matching):

- Excel/CSV tooling (openpyxl, csv module, pandas IO) or demonstrable Excel automation work.
- REST API work (requests/fetch integration examples).
- Version control (Git) and basic coding best practices visible in public profiles.

Nice-to-have skills:
